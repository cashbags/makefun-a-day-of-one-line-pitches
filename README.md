A Node 22 program that writes one sentence to /output/entry.txt — a 166-character pitch for a friend who has never coded: you already did the hard part, you had the idea, so just tell an AI agent on make.fun what you want, in your own words, and try the first version it builds for you.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
